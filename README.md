# Game Broth — проверка Android + Perchance

Минимальный APK для проверки настоящей сетевой генерации Perchance в Android WebView.
Это диагностический прототип; русификация самого MNO ещё не выполнена.

Кнопки:
- **Игра** — исходный MNO RPG Engine.
- **Текст** — официальный пример ai-text-plugin: можно запросить ответ по-русски.
- **Картинка** — официальный пример text-to-image-plugin.

ИИ работает на серверах Perchance. В APK нет API-ключей, прямых обращений к закрытым endpoint, обхода CAPTCHA, подмены User-Agent или отключения TLS-проверки.

## Результат проверки 08.11.2026

APK собран и запущен на Android 15. Perchance в WebView показал проверку Cloudflare до генерации. Поэтому совместимость генерации с APK пока не подтверждена. В браузере русский игровой ход, изображение и восстановление сохранения проверены успешно.

Подробности и границы вывода: [COMPATIBILITY.md](docs/COMPATIBILITY.md).

## Проверка

Workflow `Android Perchance compatibility probe` собирает устанавливаемый debug APK и запускает его в Android-эмуляторе. Три независимые проверки:
1. Настоящий русский ответ в текстовом генераторе.
2. Настоящее готовое изображение с указанным промптом.
3. Создание героя MNO и поиск сохранённого приключения после перезапуска Activity.

Отдельный артефакт содержит JSON-результаты, дерево доступности и скриншоты. Зелёная сборка APK сама по себе не означает успешную генерацию. Финальный шаг требует трёх PASS.

Если сайт запросит проверку человека, тест останавливается на этом этапе и сохраняет причину. Такая неудача не доказывает, что Perchance не работает на обычном телефоне.

Проверка перезапуска Activity не равнозначна проверке после принудительной остановки процесса или перезагрузки телефона. Это отдельные следующие проверки.

Исходный движок: [MNO RPG ENGINE by mnomno](https://perchance.org/mnoengine).
