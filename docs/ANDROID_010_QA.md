# Game Broth Hub 0.10

По запросу пользователя локальная заглушка из 0.9 заменена двумя отдельными пустыми страницами Perchance. В наборе пять игр и два независимых резерва. Новые страницы сохранены в аккаунте пользователя, переведены в unlisted и повторно открыты по публичным URL. На обеих видны обычное меню сайта, edit и account; у посетителя без входа сайт показывает login. Пять игровых страниц не редактировались.

| Пункт | URL |
| --- | --- |
| Заглушка 1 | https://perchance.org/j4o3qot7f6 |
| Заглушка 2 | https://perchance.org/1x315uqdpf |

Исходники страниц находятся в `stubs/`. В них нет ИИ, игры или пользовательских сохранений. Они нужны для дальнейшего независимого редактирования.

APK открывает эти страницы с настоящей оболочкой Perchance. Скрытие пустого нижнего резерва применяется к обоим URL, верхнее меню сохраняется. Действие «Открыть в браузере» доступно для обоих пунктов. Выбор старой локальной заглушки при обновлении переносится на первую страницу; предусмотрен перенос старого адреса из восстановленного состояния WebView.

Версия: 0.10, versionCode 10. Package и ключ обновлений сохранены. Иконка из 0.9 сохранена.

Проверены 55 локальных тестов правил и медиа. CI run `42765452587` на коммите `8419ef208cb9076031720662f74bd7d8ad99ccd5` завершился успешно: 22/22 Android-проверки (по 11 при 390 и 320 dp), две браузерные интеграционные проверки, Android Lint без ошибок.

Выдаваемый release APK проверен SDK apksigner. Совпадение сертификата обновлений подтверждено; package, versionCode 10, versionName 0.10, icon/roundIcon и отсутствие debuggable проверены в итоговом manifest. В production assets находятся только `compact-ui.css` и `compact-ui.js`; старой локальной заглушки и тестовых ответов нет.

Android-тесты используют API 35 и ширины 390/320 dp с локальными тестовыми ответами. Для новых страниц проверяются перенос старого выбора, оба пункта меню, URL Perchance, наличие верхней навигации login/edit, отсутствие экспортного моста, ширина и высота окна, возврат, открытие во внешнем браузере и перезапуск. Сетевая авторизация внутри APK не автоматизируется; реальные страницы и их редакторы проверены отдельно в браузере при создании.
