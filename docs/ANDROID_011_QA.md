## Изменения и совместимость

Список хранится в `gameLibraryV1` в прежних настройках Activity. Первое открытие переносит исходные семь страниц и `selectedGame`, включая прежнюю локальную заглушку. Названия, идентификаторы и URL хранятся отдельно от WebView/localStorage игр. Черновик мастера хранится отдельно и восстанавливается при следующем запуске. Повреждённая библиотека не перезаписывается: редактирование отключается с сообщением.

Создание пустой игры открывает `https://perchance.org/blank#edit`. Копирование открывает редактор оригинала и объясняет штатные действия Perchance: для собственной страницы `settings → duplicate it`, для чужой `save`. После сохранения пользователь подтверждает название и новую ссылку через «Добавить в набор». APK не обращается к закрытым API и не пытается копировать только HTML вместо полного проекта. Игровые сохранения не клонируются вместе с кодом.

Переименование меняет только подпись в APK. Удаление записи из набора не удаляет страницу или данные игры. Нативные мосты старых игр сохраняют прежние ограничения по origin; новые страницы используют обычный интерфейс Perchance. Совместимость экспорта произвольных новых генераторов с WebView этим выпуском не расширялась.
