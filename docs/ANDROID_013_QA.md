# Hub 0.13 — запуск создания из APK

Исходный код выпуска: `2eaecb7f3be8d110f510a1558d9e215cac0680f2`.

## Исправленное поведение

В 0.11/0.12 действие «Создать копию» открывало исходную страницу и ожидало, что пользователь самостоятельно выполнит копирование в Perchance. Мастер мог показать пустое поле ссылки до создания страницы. Проверки получения ссылки охватывали лишь окончание операции.

В 0.13 после задания названия APK открывает исходный редактор и запускает обычные элементы Perchance: edit, затем settings → duplicate it для своей страницы; для чужой страницы или пустого шаблона — save после явного определения отсутствия владения. Наличие скрытой кнопки settings само по себе не считается признаком чужой страницы. Вход и проверки сайта завершаются пользователем в его интерфейсе. Логины, пароли и токены нативная часть не читает. Прямые HTTP-запросы APK к закрытым API отсутствуют.

После результата текущей операции APK проверяет новый URL, сохраняет запись под заданным названием и открывает её. Старая ссылка Success! исключена сравнением с результатом на момент запуска; пассивные сообщения о ссылках не используются как завершение активного создания. Пустой диалог URL открывается только по явному выбору «Вставить ссылку уже созданной игры».

Состояние операции и идентификатор попытки сохраняются отдельно от библиотеки. После перезапуска операция, которая могла уже обратиться к серверу, автоматически не повторяется. Пользователь может проверить результат, вставить адрес готовой страницы или явно разрешить повтор. Предупреждения Perchance показываются обычным WebView-диалогом и переводят мастер в состояние проверки результата. Исходная страница не сохраняется вместо копирования; исходники существующих игр не изменялись.

## Проверка и пределы подтверждения

Новые Android-сценарии начинают операцию через меню APK и ввод названия. Тест больше не нажимает за пользователя кнопку создания тестовой копии перед проверкой ссылки. Модель страницы воспроизводит текущие элементы официального редактора (`editButton`, `settingsButton`, `saveButton`, `loginButton`, `settingsModalEl`, результат `duplicateGeneratorStatus`). Проверяются полный путь пустой страницы, полный путь копии, ровно один вызов штатного действия, отсутствие сохранения оригинала, ожидание входа, продолжение после входа, старая ссылка в DOM, запрет повторного запроса после перезапуска и ручное восстановление уже созданной страницы.

Тесты выполняются с локальными ответами на URL Perchance в настоящем Android WebView. Это проверка кода APK и взаимодействия с моделью интерфейса, а не подтверждение успешного серверного копирования в аккаунте пользователя.

В живом браузере проверены текущий публичный редактор и форма входа; изучен текущий публичный код его кнопок. Запрос защищённого входа был прерван, успешный вход не подтверждён. Создание на сервере и работа с реальной CAPTCHA **не проверены**. Проверки на телефоне пользователя не выполнялись.
