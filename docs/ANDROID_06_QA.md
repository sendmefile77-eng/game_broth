# Проверка Hub 0.6

Рабочая FANTA: https://perchance.org/n89crmz16e . Сохранена отдельным генератором; доступна по ссылке, скрыта из публичных списков. Существующая страница Broth не редактировалась.

Код сборки: `aee04ca9651fcc55e2c34c1b30a4f7faed68cc47`. GitHub Actions: https://github.com/sendmefile77-eng/game_broth/actions/runs/42618757442 . Оба задания завершились успешно.

- 29 проверок Broth и 16 проверок FANTA прошли.
- Автономный браузерный тест FANTA подтвердил трёхшаговый старт, ручной бросок, повтор неудачной картинки, JSON-перенос двух кадров, сохранение исходной кампании и отсутствие переполнения на 320/390 px.
- На Android 15 выполнены по шесть проверок на ширинах 320 и 390 dp: навигация/версии, служебная панель и «Назад», размеры текста, клавиатура, прежние игры, FANTA. В итоговом прогоне системных окон зависшего Pixel Launcher не было.
- FANTA проверена в настоящем MainActivity/WebView на локальных тестовых страницах: три шага, просмотр кадра и закрытие системной кнопкой, достижение нативного ACTION_CREATE_DOCUMENT с именем `fanta-whfb-turn-0.json`, отклонение формата Broth из origin FANTA, сохранение выбранной игры и кадра после перезапуска Activity без повторной генерации.
- Тестовые ответы моделей присутствуют только в тестовом APK. В рабочем APK их нет.
- В опубликованной игре реальные плагины Perchance создали начальную сцену, затем сцену рискованной передачи документа; системный бросок 5+5=10 сохранился с ходом 1. После перезагрузки восстановились тот же исход и обе иллюстрации. Крупный просмотр настоящего кадра проверен визуально.
- Облачный браузер показал «Файл сохранения подготовлен», но его инструмент не вернул скачанный JSON; это не считается подтверждением скачивания в этой среде. Скачивание/импорт подтверждены отдельным автономным браузерным тестом, а нативный маршрут экспорта — Android-тестом.

APK подписан сохранённым личным ключом Hub. Совпадение сертификатов 0.5 и 0.6 проверено официальным apksigner. SHA-256 APK 0.6: `56ff2f73caca1f3e4e0e59e2de3f5175ec01330598c418eef560fe8bc36b47a9`.

Проверки не заменяют запуск на физическом телефоне и не подтверждают сетевую генерацию внутри Android WebView: реальные модели проверены в браузере, Android-интерфейс — на изолированных тестовых ответах. Точное сохранение лиц между разными рисунками модель не гарантирует.
