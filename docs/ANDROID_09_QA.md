# Game Broth Hub 0.9

Изменения выполнены в Android-приложении. Страницы и код Perchance в этой работе не менялись.

## Что изменилось

- Добавлен собственный значок: медный котёл с игровым кубиком. В APK входят пять плотностей, адаптивная иконка, монохромный вариант Android 13+ и оформление запуска Android 12+.
- Возврат по истории WebView обновляет название и выбранную игру в оболочке. Раньше заголовок и проверки мостов могли относиться к другой игре.
- Поворот телефона сохраняет тот же WebView и открытый документ; экран игры не создаётся заново.
- В меню добавлена информация о версии. Номер APK обновлён до 0.9 / versionCode 9.
- Убраны вызовы Set.of, недоступные до Android 11; минимальная версия по-прежнему Android 8 / API 26.
- Вместо вручную заданных числовых идентификаторов используются Android resource IDs. В сборку добавлена проверка Android Lint.
- Пять опубликованных игр сохранены. Шестой пункт — нейтральная локальная страница «В разработке»: работает без сети, не запускает генерацию и не получает мост экспорта. Это заглушка, не готовая шестая игра.
- Для выдачи собирается release-вариант без режима отладки и подписывается прежним ключом обновлений.

## Проверки

55 проверок состояния, медиа, галереи и игровых правил прошли локально. Две браузерные интеграционные проверки прошли в CI.

Android проверяется на API 35 при ширине 390 и 320 dp. Используются локальные страницы с тестовыми ответами: это проверяет настоящее приложение, WebView, клавиатуру, доступность, экспорт через системный выбор файла и восстановление, без запросов к Perchance и генераторам.

Новые проверки: возврат между играми с восстановлением заголовка; локальная заглушка и возврат из неё; упакованная адаптивная иконка и окно версии; поворот без пересоздания документа или повторной генерации.

Итог: **22/22 Android-проверки пройдены**, по 11 при 390 и 320 dp. Workflow run `42711214282` завершился успешно; исходный коммит `ce196e07c254901c22a2a7d96d122f24e8376198`. Android Lint завершился без ошибок.

Инструментальные проверки используют debug-вариант с теми же исходниками приложения и ресурсами. Выдаваемый APK — отдельно собранный release-вариант. В его итоговом manifest проверены package, versionCode 9, versionName 0.9, icon/roundIcon и отсутствие режима отладки. ZIP цел, тестовых страниц и mock-ответов среди рабочих assets нет. Подпись APK проверена SDK apksigner и совпадает с ключом обновлений 0.5–0.8.

## Границы

Тестовый выбор файла проверяет передачу JSON в Android picker; запись в произвольный пользовательский провайдер файлов не имитируется. Работу модели и CAPTCHA определяет Perchance. На телефоне пользователя сетевой вход повторно в этой работе не проверялся. Android 8–10 проверены статическим анализом совместимости, отдельный эмулятор этих версий не запускался.
