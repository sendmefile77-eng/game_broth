# APK 0.4 — компактный интерфейс

## Исправление 0.5 по отзыву пользователя

Верхняя строка самого Perchance остаётся видимой: доступны вход/аккаунт и остальные команды сайта. Внизу постоянно видна кнопка с версией APK, версией картинок генератора и кратким статусом; она раскрывает подробную панель. Компактный режим скрывает только повторяющийся заголовок игры, день из которого продублирован в нативной строке.

Сборка 0.5 называется Game Broth Hub, applicationId `com.sendmefile77.gamebroth.hub`; устанавливается рядом с прежними прототипами. Прежние данные не удаляются. Новые Hub-сборки подписываются одним сохранённым личным ключом вне репозитория; исходники не содержат ключа и пароля.

Изменения существуют только в Android-приложении. Исходники и настройки опубликованного генератора Perchance не обновляются.

Вместо нескольких шапок остаётся одна нативная строка с меню, названием игры и днём. История читается слева направо шрифтом 17 px с межстрочным интервалом 1,6. Внизу — строка действия, отправка и переход дня. Служебные сообщения и управление ИИ открываются через меню. Обычное оформление, размер текста, выбор обеих игр и открытие браузера доступны там же.

Переоформление включается только на двух известных страницах оболочки и внутри iframe Broth. Для неподдерживаемого WebView остаётся обычное оформление. Данные кампании, промпты, генерация, IndexedDB и места рекламных блоков не меняются. Обработчик «Назад» сначала закрывает просмотр изображения или раскрытую панель.

`CompactUiInstrumentation` запускает настоящий MainActivity и WebView на Android, подменяя только сетевые ответы локальными HTML-страницами. Проверяются интерфейс, origin-проверки моста, клавиатура, возврат обычного вида, размер текста, черновик ввода, перезагрузка и переключение игр. Это проверка интерфейса на эмуляторе, а не подтверждение сетевой генерации или работы на физическом телефоне. Файлы тестовых страниц входят только в тестовый APK.

Версия `0.4-compact` устанавливается как **Game Broth Compact** рядом с прежним APK, applicationId `com.sendmefile77.gamebroth.compact`. Старое приложение и его локальные кампании сохраняются. Для переноса кампании: экспортировать JSON в разделе «Сейвы» старого приложения и импортировать его в новом. Такой способ не требует удаления прежней версии, подписанной другим временным debug-ключом сборки.
