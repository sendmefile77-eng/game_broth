# Проверка Android + Perchance — 08.11.2026

## Итог

Браузерная связка MNO + Perchance работает. Работоспособность генерации внутри APK **не подтверждена**: Android WebView был остановлен проверкой Cloudflare до открытия генераторов.

| Проверка | Результат |
|---|---|
| Русский текст через ai-text-plugin в браузере | PASS: получен настоящий ответ |
| Изображения через text-to-image-plugin в браузере | PASS: получены изображения по заданному промпту |
| Игровой ход MNO по-русски | PASS: ведущий ответил по-русски |

| Сборка APK и тестового APK | PASS |

| Генерация текста, картинки и восстановление MNO внутри APK | BLOCKED: Cloudflare human/security verification |

- Android 15, API 35.
- WebView: `com.google.android.webview 124.0.6367.219`.
- Тестировался исходный MNO и официальные примеры Perchance, без API-ключей.
- Коммит приложения и теста: [8eb2356](https://github.com/sendmefile77-eng/game_broth/commit/8eb2356744062dada70ec414ad4c4546b46b833b).
- [Завершённый запуск теста](https://github.com/sendmefile77-eng/game_broth/actions/runs/42513286061).
- Артефакт `perchance-android-probe-evidence` содержит результаты, дерево доступности и PNG каждого этапа.
- Сырой результат: [android-15-result.json](android-15-result.json).

На экране Android отображались `Just a moment...`, `Performing security verification` и объяснение защиты от ботов. Проверку не решали и не обходили. Реальные запросы на генерацию внутри APK не были выполнены.

## Пределы вывода

Блокировка облачного эмулятора не доказывает блокировку обычного телефона. Её точная причина не установлена. Тест на физическом OnePlus не проводился: устройство недоступно из этой среды.

Следующая необходимая проверка — установить диагностический APK на физический телефон и проверить доступ к страницам «Игра», «Текст» и «Картинка». Пока этот этап не пройден, обещать стабильную бесплатную генерацию в APK нельзя.

Это диагностический APK с исходными страницами Perchance. Русификация интерфейса MNO ещё не выполнена.
