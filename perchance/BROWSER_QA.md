# Проверка опубликованной игры

Дата: 9 ноября 2026. URL: https://perchance.org/game-broth-veyre

## Личные галереи и мобильная разметка 0.7

- 29 проверок прошли: подбор изображений по участникам, разделение двух галерей, общий кадр для нескольких персонажей, сохранение галереи кандидата при найме, смена набора, удаление старой записи журнала, JSON-перенос архива, дедупликация и отклонение повреждённых метаданных.
- Подготовлены компактные карточки команды, раскрывающиеся личные галереи, миниатюры и просмотр архивного кадра независимо от наличия записи в текущем журнале. Обновление сохранено на Perchance (`saved`), отдельная публичная вкладка загружает версию `Картинки 0.7`. В реальном UI у Миры три изображения, у Тильды два; личная сцена Миры не попадает к Тильде, общий кадр входит в обе галереи.
- Исходная тестовая кампания экспортирована в отдельный файл. Для UI подготовлена отдельная кампания с двумя сотрудниками и шестью существующими неграфическими изображениями; новых генераций для этого теста не требуется. Исходная кампания сохраняется в браузерном архиве.
- Промпты повествования и генерации не менялись: блок narrate() в app.js и pump() в gallery.js совпадают с текущими опубликованными версиями. media.js не редактируется.
- После импорта тестовой кампании с удалённой из журнала записью S0003 и перезагрузки её изображение осталось в личной галерее и открылось в просмотре. Браузерный экспорт повторно прочитан: 5 уникальных изображений галерей, всего 6 изображений в файле; все архивные ссылки обеспечены данными, даже при отсутствии S0003 в журнале.
- Узкий предпросмотр проверен на 390×688 и ширине 320 CSS px. В обоих случаях `body.scrollWidth === body.clientWidth`, низ основной прокрутки совпадает с верхом футера. Навигация и кнопки футера — 48 px. Мобильный просмотр занимает 390×688 px, кнопки увеличения/закрытия — 44 px; увеличение создаёт прокрутку внутри окна, а не растягивает страницу.
- Подтверждение мобильного вида сохранено полным снимком `team-gallery-mobile-v07-1794206662483.jpg`. Проверка выполнена в узком iframe браузера, а не на физическом Android; экранная клавиатура и системный жест «Назад» в этой версии не проверялись.

- Проверен реальный просмотр существующей неграфической сцены S0003: окно открывается, показывает исходное изображение 768×512 целиком и увеличивает его до 1536×1024. ## Привязка иллюстраций 0.5

- 24 из 24 локальных проверок прошли. Проверены ожидание завершения повествования, использование `aiText` вместо команды игрока, отсутствие шаблонного кадра при ошибке описания, отказ от устаревшего результата, сохранение состава сцены при новом поиске и восстановление прерванного повествования после загрузки.
- Проверка синтаксиса `app.js`, `media.js`, `gallery.js` прошла. Полный рабочий `app.js` восстановлен из версии, реально развёрнутой на Perchance: в текущем GitHub-файле обнаружен оборванный фрагмент с комментарием-заглушкой.
- После ручного входа пользователя обновление сохранено в существующем генераторе; редактор показал `saved`. Публичная страница отображает `Картинки 0.5`. Первый запрос сохранения получил некорректный HTML-ответ; один повтор завершился успешно.
- Две существующие иллюстрации были перерисованы по тексту. Для первой встречи кадр показывает троих ожидающих людей в приёмной с фонарями; для пролога — пустую приёмную. Это не подтверждает точное сохранение лиц персонажей.
- В живой игре отправлено новое неграфическое действие S0003: Мира Медная ставит синий чайник на деревянный стол у окна. UI сначала показал ожидание текста, затем подготовку и рисование кадра. Сгенерированный рассказ описал это действие; на изображении видны синий чайник, стол, окно и Мира с зелёной кожей, тёмными волосами и бордовым жилетом. Подпись содержит точную цитату: «Мира, аккуратно опуская синий чайник на массивный стол у окна».
- Перезагрузка публичной страницы восстановила тот же кадр и подпись; очередь показывает `Все иллюстрации сохранены`. День 1, казна 24, репутация 0 остались прежними. Проверка проводилась в облачном браузере; физический Android не проверен. Пиксельная точность всех возможных сцен не гарантируется моделью.

## Исправление очереди 0.4

- В HTML добавлены версии URL JS/CSS для обновления кэша. В панели изображений отображается `Картинки 0.4`.

После изменения предпочтений пользователем браузерная проверка 0.4 завершена: свежая партия создала первую иллюстрацию, затем три портрета 512×768 и иллюстрацию встречи 768×512. ## Границы проверки

- Облачный инструмент не получил событие системного выбора файла внутри iframe. UI-импорт файла не подтверждён; проверка формата сохранения и открытие из локального архива подтверждены. Нельзя выдавать это за проверенный перенос между двумя устройствами.
- Проверка узкой разметки в браузере не заменяет тест на физическом Android с экранной клавиатурой и системными панелями.
- APK 0.3 собран, но его новая навигация и системные диалоги не проверены на физическом устройстве. Предыдущие результаты CI с Cloudflare относятся к старому диагностическому APK.
- Сохранённые портреты стабильны; точное совпадение лиц между разными сюжетными иллюстрациями модель не гарантирует. Облачная синхронизация и полная механика MNO не реализованы.
