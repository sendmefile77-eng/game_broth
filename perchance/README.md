# Ржавый Фаллос — Perchance

Играть: https://perchance.org/game-broth-veyre (сохранён в аккаунте пользователя; доступен по ссылке, скрыт из публичных списков).

Оригинальный русскоязычный менеджер фэнтезийного заведения. Неграфическое повествование; все персонажи взрослые. Экономика, найм, смены, усталость, уровни, строительство и календарь рассчитываются кодом. ИИ Perchance описывает уже подтверждённые события и создаёт обычные иллюстрации интерьера.

## Размещение

В редакторе Perchance содержимое `main.pjs` идёт в поле списков, `index.html` — в поле HTML. Файлы из `src/` загружаются через публичный файловый менеджер генератора в каталог `src`. Сохранить как собственный генератор. Ключ API и отдельный сервер не требуются. Доступность генерации определяется самим Perchance; блокировки/проверки браузера не обходятся.

## Состояние и сохранения

IndexedDB хранит игры, настройки и изображения на текущем устройстве. Раздел «Сейвы» экспортирует JSON `game-broth-export/1`, включая последнюю иллюстрацию. Сохранения исходного текстового промпта RF3.0 не импортируются: это самостоятельный формат. Старые кампании остаются в локальном списке после создания новой игры. Для переноса между браузерами/устройствами нужен экспорт и импорт файла. Очистка данных браузера удалит локальные кампании.

Время меняется только кнопками «Закрыть день» и «Следующее утро». Повторная обработка номера действия не применяется. Дневной отчёт нельзя начислить дважды. Просмотр страниц не создаёт ход. Иллюстрации изменяют только `mediaSeq`, а не номер игрового действия. Вывод ИИ вставляется как текст, а не HTML.

## Проверки

`node --test perchance/core.test.cjs`

`node --check perchance/src/app.js`

Проверяется баланс дня, повторная отправка, нехватка денег, отдых, долг, фиксированный набор кандидатов, строительство, вместимость, импорт и отсутствие влияния диалога на экономику. Мобильная разметка использует отдельную прокручиваемую область, `visualViewport` и safe-area; футер занимает собственную строку, а не перекрывает содержание.

## Ограничения

Свободный ввод создаёт диалог/описание без финансовых изменений; экономические действия доступны кнопками. Генерация изображения сейчас показывает обстановку дома, без фиксации внешности персонажей. Нет облачной синхронизации сохранений, полной механики MNO, совместной игры или графического сексуального содержания. При сбое ИИ состояние уже сохранено и игра продолжается с обычной записью события.
