# Ржавый Фаллос — Perchance

Играть: https://perchance.org/game-broth-veyre (сохранён в аккаунте пользователя; доступен по ссылке, скрыт из публичных списков).

Оригинальный русскоязычный менеджер фэнтезийного заведения. Неграфическое повествование; все персонажи взрослые. Экономика, найм, смены, усталость, уровни, строительство и календарь рассчитываются кодом. ИИ Perchance описывает уже подтверждённые события и создаёт обычные иллюстрации интерьера.

## Размещение

В редакторе Perchance содержимое `main.pjs` идёт в поле списков, `index.html` — в поле HTML. Файлы из `src/` загружаются через публичный файловый менеджер генератора в каталог `src`. Сохранить как собственный генератор. Ключ API и отдельный сервер не требуются. Доступность генерации определяется самим Perchance; блокировки/проверки браузера не обходятся.

## Состояние и сохранения

IndexedDB хранит игры, настройки и изображения на текущем устройстве. Раздел «Сейвы» экспортирует JSON `game-broth-export/2` (импорт /1 поддерживается), включая все портреты и иллюстрации журнала. Сохранения исходного текстового промпта RF3.0 не импортируются: это самостоятельный формат. Старые кампании остаются в локальном списке после создания новой игры. Для переноса между браузерами/устройствами нужен экспорт и импорт файла. Очистка данных браузера удалит локальные кампании.

Время меняется только кнопками «Закрыть день» и «Следующее утро». Повторная обработка номера действия не применяется. Дневной отчёт нельзя начислить дважды. Просмотр страниц не создаёт ход. Иллюстрации изменяют только `mediaSeq`, а не номер игрового действия. Вывод ИИ вставляется как текст, а не HTML.

## Проверки

`node --test perchance/core.test.cjs perchance/media.test.cjs perchance/gallery.test.cjs`

`node --check perchance/src/app.js`

Проверяется баланс дня, повторная отправка, нехватка денег, отдых, долг, фиксированный набор кандидатов, строительство, вместимость, импорт и отсутствие влияния диалога на экономику. Мобильная разметка использует отдельную прокручиваемую область, `visualViewport` и safe-area; футер занимает собственную строку, а не перекрывает содержание.

## Ограничения

Свободный ввод создаёт диалог/описание без финансовых изменений; экономические действия доступны кнопками. Все видимые персонажи получают сохранённый портрет; каждое событие — собственную иллюстрацию. Портрет повторно используется при найме. Совпадение лиц в разных сюжетных иллюстрациях не гарантируется моделью. Нет облачной синхронизации сохранений, полной механики MNO, совместной игры или графического сексуального содержания. При сбое ИИ состояние уже сохранено и игра продолжается с обычной записью события.

Картинки создаются по одной в фоне, не блокируя ходы. При ошибке есть повтор; ошибки сети/проверки безопасности приостанавливают очередь. Для импорта доступен выбор файла и вставка JSON.

## Иллюстрации по тексту — 0.5

Сначала завершается повествование события. Затем отдельный вызов текста выделяет один наблюдаемый момент, точную цитату из рассказа и состав участников. Генератор картинок получает этот кадр и сохранённую внешность участвующих персонажей. Общие шаблоны «утро», «найм», «разговор» удалены. Смена набора кандидатов не меняет сохранённый состав старой сцены.

Кадр принимается только с цитатой, действительно присутствующей в итоговом тексте, и известными идентификаторами персонажей. При некорректном ответе доступен повтор, посторонняя шаблонная картинка не подставляется. Результат устаревшего запроса отбрасывается при изменении текста или кампании. Подпись картинки показывает цитату изображаемого момента. Это проверка привязки данных, а не компьютерная проверка пикселей: точность исполнения промпта ограничена моделью изображений.

Старые иллюстрации событий перерисовываются один раз по новой схеме, начиная с последних событий. Портреты и игровые показатели сохраняются. Для текущей версии APK достаточно заново открыть игру по сети; внизу страницы отображается «Картинки 0.5».

## Просмотр картинок — 0.6

Портреты показываются целиком с сохранением исходных пропорций. Кнопка «Открыть крупно» открывает диалог с увеличением и прокруткой, закрытием кнопкой или Escape. Это изменение отображения, а не повышение разрешения или исправление анатомии в пикселях изображения.

Промпты, настройки содержания, seed и очередь генерации не меняются. Существующие изображения автоматически не перерисовываются. Опубликованный генератор может содержать пользовательские настройки генерации, отличающиеся от исходников репозитория; изменение просмотра накладывается поверх его текущей версии без замены этих настроек.
