# Две пустые заглушки

Независимые страницы в аккаунте пользователя: «Заглушка 1» и «Заглушка 2». URL и origin находятся в `deployment.json`. Обе страницы unlisted: доступны по ссылке, не показываются в общем каталоге. Обычное меню Perchance, авторизация и редактор предоставляются самим сайтом.

`stub-1.pjs` / `stub-2.pjs` — поле списков; `template.html` — общее поле HTML. Страницы не содержат ИИ, игровых механик или сохранений. Редактирование одной не меняет вторую или пять игр.

`node stubs/build-fixtures.cjs` собирает тестовые страницы Android из того же шаблона. Добавленный обработчик метрик находится только в инструментальном тестовом APK.
